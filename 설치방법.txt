실제 덕트 속도·속도압 계산기 — GitHub Pages 업로드 방법

구성 파일
1. index.html         계산기 본체
2. manifest.json      홈 화면 설치 정보
3. service-worker.js  오프라인 캐시
4. 설치방법.txt       이 안내문

GitHub 업로드
1. GitHub에서 새 저장소(repository)를 만들거나 사용할 저장소를 엽니다.
2. 저장소 첫 화면에서 Add file → Upload files를 선택합니다.
3. ZIP 파일을 먼저 PC/휴대폰에 압축 해제합니다.
4. 압축 해제한 폴더 안의 index.html, manifest.json, service-worker.js 세 파일을 업로드합니다.
   ZIP 파일 자체만 업로드하면 웹앱이 실행되지 않습니다.
5. Commit changes를 누릅니다.
6. 저장소 Settings → Pages로 이동합니다.
7. Build and deployment에서 Deploy from a branch, Branch는 main, 폴더는 /(root)를 선택하고 Save 합니다.
8. 잠시 기다린 뒤 Pages에 표시된 주소를 엽니다.

계산 방식
- 필요환기량 Q 입력 단위: m³/min
- 실제 유속은 사용자가 직접 입력한 실제 덕트 직경과 Q로 계산합니다.
- 속도압 VP = 0.5 × 공기 밀도 × 실제 유속² (Pa)
- mmH₂O = Pa ÷ 9.80665

중요
- 실제 덕트의 제작 규격은 제조사·재질·현장 설계에 따라 다를 수 있으므로 실제 시공 전 확인하세요.
- 오프라인 기능은 GitHub Pages 주소를 한 번 온라인으로 열어 서비스 워커가 등록된 이후 지원되는 브라우저에서 작동합니다.
- 기존 저장소에 업로드하면 기존 index.html을 덮어쓸 수 있습니다. 기존 계산기를 유지하려면 새 저장소를 사용하는 것이 안전합니다.

속도압으로 실제 유속 역산
- 교재 공식: V = 4.043 × √VP
- VP 입력 단위: mmH₂O
- 역산 유속 단위: m/s

참고: 이 계산기는 실제 덕트 내 유속과 속도압을 계산하며, 마찰손실 계산 기능은 포함하지 않습니다.

계산 범위: 상용 덕트 규격 선정과 마찰손실 계산은 적용하지 않습니다. 실제 덕트 직경을 직접 입력해 유속·속도압만 계산합니다.

공기 밀도 입력은 제외했습니다. 실제 유속으로부터 교재 공식 V = 4.043 × √VP를 역산해 속도압을 계산합니다. 따라서 VP는 mmH₂O 기준이며 Pa는 1 mmH₂O = 9.80665 Pa로 환산합니다.
